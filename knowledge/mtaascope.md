MtaaScope is David's localized portfolio case study based on the Google ADK retail-ai-location-strategy sample. It reframes the sample as a retail location intelligence system for East African entrepreneurs, franchise operators, SME lenders, and commercial real estate teams.

The original ADK sample is a seven-stage multi-agent pipeline for retail site selection. It uses market research, Google Maps Places API competitor mapping, Python/pandas code execution for gap analysis, strategy synthesis, HTML report generation, image generation, and optional AG-UI/CopilotKit pipeline visualization.

Localized product concept:

Choosing a business location is expensive and risky. Small businesses often rely on instinct, rent pressure, or copying competitors. MtaaScope turns that decision into an evidence-driven workflow for questions like where to open a cafe, pharmacy, salon, mini-mart, clinic, hardware shop, or quick-service restaurant.

Core workflow:

The user provides a business type and target location. The system extracts the location and business category, researches the market, maps competitors, scores opportunity gaps, synthesizes strategy, and generates an executive-style report with recommendations and assumptions.

Agent responsibilities:

The intake agent structures the request. The market research agent gathers live context. The competitor mapping agent searches places data. The gap analysis agent uses code execution for quantitative scoring. The strategy advisor interprets tradeoffs. The report generator creates a polished report. The infographic generator produces a visual summary.

Business value:

MtaaScope can help entrepreneurs avoid weak locations and help lenders assess whether a business plan is realistic. The output should include opportunity gaps, viability score, risk factors, recommended positioning, alternative locations, and next-step validation.

Recruiter framing:

MtaaScope should be presented as an adapted and localized ADK case study. It demonstrates David's ability to turn a generic agent sample into a regionally relevant product concept with tools, structured outputs, data assumptions, and practical business value.
